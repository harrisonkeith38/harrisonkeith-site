# Harrison Keith — Persistent Agent Brand Rules & Guardrails

> This file governs all AI-assisted coding, design, and content generation in this repository.

## 1. Core Brand Standards
- **Entity:** Personal identity for Harrison Keith (not a commercial business, apparel brand, or athletic company).
- **Creative Direction:** Technical Performance meets Modern Minimalism (Salomon, Arc'teryx, S-Works, YETI restraint).
- **Primary Identifier:** `HARRISON KEITH`
- **Secondary Identifier:** `HK`

## 2. Strict 6-Color System (NO Other Colors Permitted)
- **Carbon:** `#141414` (Primary neutral)
- **Concrete:** `#A6A6A6` (Secondary neutral & dividers)
- **Chalk:** `#F4F4F4` (Canvas background & negative space)
- **Signature Stripes (Strict Order):**
  1. Signal Yellow: `#E4BD25`
  2. Racing Red: `#B74438`
  3. Alpine Blue: `#438CA9`
- NEVER introduce brown, cream, bone, neon, or unapproved accent colors.

## 3. Strict Prohibitions
- NEVER invent slogans, taglines, or positioning statements (e.g. NO "A Strategic Operator", "Built Through Exploration", "Strategy. Leadership. Exploration.").
- NEVER use latitude/longitude coordinates anywhere on the site.
- NEVER use military or tactical imagery as a defining brand element.
- NEVER use dense topographic patterns, elevation markers, or compass graphics.
- NEVER create branded apparel, merchandise, hats, or physical stationery.
- NEVER use generic stock photography to imply a lifestyle.

## 4. Typography System
- **Primary Display:** Extended geometric grotesque (GT America Extended style) for major headlines and wordmarks.
- **Secondary Functional:** Clean structural sans (FF DIN style) for body copy, navigation, and descriptions.
- **Accent Technical:** Squarish technical sans (Eurostile Next style) for micro labels, indexes, and technical data.
